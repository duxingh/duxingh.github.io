*Code: The Hidden Language of Computer Hardware and Software* by [Charles Petzold](https://www.charlespetzold.com/) is a classic book that explains how computers work from the ground up, using everyday examples like Morse code, Braille, and flashlights to build up to complex concepts like logic gates, binary, and microprocessors.

## Chapter 6. Logic with Switches

Switches connected in series can implement the AND logical operation:

![Switches in series](switches-in-series.jpeg){: w="200" }

Switches connected in parallel can implement the OR logical operation:

![Switches in parallel](switches-in-parallel.jpeg){: w="200" }

Placing a switch on a short wire can achieve the NOT logical operation.
